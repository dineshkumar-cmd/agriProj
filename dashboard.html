Module 1 — C2f-Attention
Injected at deepest backbone stage (P5, 256ch). Applies Multi-Head Self-Attention (4 heads) over spatial tokens via learnable residual gate γ=0 at init.

Goal Suppress background noise (crates/shadows) and emphasize tuber surface regions.
Module 2 — GatedFusion
Replaces all 4 static Concat nodes in neck. Learnable softmax-gated weights w₁, w₂ per-layer, initialized equal, learned during training.

Goal Adaptive weighting — fine details for small spots, deep context for widespread rot.

INPUT

NEURAL NETWORK (Single Pass)
Gated-Attention YOLOv8n → bounding boxes + class labels for all 5 conditions simultaneously
POST-PROCESSING
Aggregate per-tuber labels → compute Defective Percentage for the lot
SPOILAGE PREDICTION
Defect% + environmental sensors → estimated remaining shelf-life in days
